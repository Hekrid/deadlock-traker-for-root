# Deadlock Tracker privacy policy

Deadlock Tracker is a Root app that shows Deadlock statistics.

## What Deadlock Tracker stores

For each community that installs it, in that community's own database on Root:

- The Root user id of members who link a Steam account, the Steam account id (SteamID3) and Steam
  name they linked, and when they linked it.
- The newest match and rank the match feed has already announced for them.
- The community's Deadlock Tracker settings (feed channel and options).

Nothing else is stored. Unlinking removes the member's row. Admins can unlink any member.

## What Deadlock Tracker sends elsewhere

Deadlock Tracker looks up public Deadlock and Steam data (Steam name, avatar, rank, match history, hero
stats) from the community Deadlock API (https://deadlock-api.com) by Steam account id or by the name
you search for. It does not send your Root identity, messages or anything else about you.

## Messages

If a community admin turns on the match feed, Deadlock Tracker posts linked members' new matches and
rank-ups in the chosen channel.

Deadlock Tracker is not affiliated with Valve or Steam.
